# 片场 · 视频制作工作流与本机平台

采用 **一套公共制作流程、两个内容分支、一组可复用模板**。

唯一执行入口：[视频制作总工作流](视频制作总工作流.md)。覆盖营销和教学视频，共用 Codex、本地 Qwen TTS、HyperFrames 与 FFmpeg。

## 平台启动

当前工作台：[打开片场](http://127.0.0.1:8794)。首次安装执行 `./scripts/setup.sh`；启动执行 `.venv/bin/python scripts/manage.py start`。

[运行手册](docs/运行手册.md) · [技术架构](docs/技术架构.md) · [AGENTS.md](AGENTS.md) · [实施检查与试制预览](qa/平台实施检查.md)

新增 Skills 仅在 `.agents/skills/` 维护。后台逐阶段调度 Codex；旁白使用已探测的本地 Qwen。平台状态以 STATUS.md 为准。

## 使用内容手册

1. 阅读总工作流，确定营销或教学主目标。
2. 从 [模板包](templates/README.md) 复制公共文件与对应分支，填写简报。
3. 对照 [营销填写示例](examples/marketing/README.md) 或 [教学填写示例](examples/teaching/README.md)，按阶段完善内容。
4. 按 [文件交接约定](文件交接约定.md) 维护编号、素材、时间和版本。
5. 在真实项目中执行 [试制与回归检查](试制与回归检查.md)。
