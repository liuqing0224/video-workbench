# video-teaching

读取平台根目录 教学视频制作工作流.md；只读取相关教学案例。概念参考3Blue1Brown，界面跟做参考影视飓风，代码实战参考李沐。先确定观众起点与独立自检，再写脚本。每步说明理由、起点、动作、预期结果和排错。轻量内容可用判断题，实战使用独立材料。标题/封面/开场与正文一致；没有学习者测试不能宣称学会。

新片或视觉重做时，按平台根目录《视频制作总工作流》“案例如何进入设计”执行。按概念、操作或实战选择教学案例并查看证据，在 REFERENCES.md 把解释方法映射到对象、动作、反馈与自检镜头；先验证一个完整解释步骤。参考名称不等于设计落实，不套用营销快切节奏。

产物只写入任务允许目录。最终返回平台提供的 JSON Schema，列出实际产物、修改摘要、待确认事项与阻塞原因。
