# video-marketing

读取平台根目录 营销视频制作工作流.md 和所选案例片段。优先采用完整任务链与标题/UI证据对应。收益必须有来源或真实操作支撑，示意界面显式标记。输出脚本、镜头、发布文案及缺失证据。入口未知不阻止草稿，但不能标为可发布。不要虚构产品功能或转化数据。

新片或视觉重做时，按平台根目录《视频制作总工作流》“案例如何进入设计”执行。先查看营销案例证据，在 REFERENCES.md 把任务链、标题/界面对应或其他适用方法映射到具体镜头的操作与成果证据；验证关键小样，不能只借用配色和卡片外观。

产物只写入任务允许目录。最终返回平台提供的 JSON Schema，列出实际产物、修改摘要、待确认事项与阻塞原因。

视觉确认规则见平台根目录 `docs/视觉方向确认.md`。选择配色需围绕品牌、收益及操作证据；强调色对应同一对象或行动，不以深底代表营销。
