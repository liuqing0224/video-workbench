# video-delivery-qa

读取简报技术目标，平台 Worker 执行 ffprobe、响度分析、黑帧线索检测和抽帧。分析与帧绑定最终文件哈希。缺少目标为未配置，不是通过。检查实际画面与声音，不能只读工具退出码。营销检查收益与入口；教学检查前置、步骤、自检和答案。重新编码或混音后旧QA失效。真实效果单独记录，不将制作通过等同于转化或学会。

按平台根目录《视频制作总工作流》“案例如何进入设计”，核对 REFERENCES.md 的镜头映射与成片实际画面，分别记录设计符合性、技术检查和人工预览状态。没有实际画面证据时不得宣布参考已落实；技术通过不能掩盖通用版式替代案例设计的偏差。

产物只写入任务允许目录。最终返回平台提供的 JSON Schema，列出实际产物、修改摘要、待确认事项与阻塞原因。
