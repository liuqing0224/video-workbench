## 本轮发现与处理

1. 原生 audio controls 导致内置标签崩溃：新增自定义 AudioPlayer（播放/暂停、时间、进度、错误提示），改两处音频入口。切到已有可用内置标签4，重新播放四段及正式声音均到结束；标签6崩溃页未绕过浏览器安全提示。
2. TTS / transcribe 成功被误算为声音阶段完成：阶段计算排除辅助任务。浏览器复测先显示声音阶段尚未开始，再正常启动正式时间锁定任务。
3. 整片保留小样 HTML 导致两个主入口：通过 UI 提交恢复意见，复用四镜工程，仅保留 index.html 为主入口；小样保留于历史运行。重新检查并渲染通过。
4. 新建项目默认缺少响度目标：正式导出未被误判通过。通过 UI 显式补齐本次目标，然后用“重新检查”对原始正式 MP4 建立新 QA 并完成确认。没有降低阈值或修改视频去迎合报告。

源码修复后的验证：31 项 Python 测试、5 项日志测试及前端构建通过；Python 测试有2条依赖弃用警告。
