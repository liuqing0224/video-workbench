## 执行方式

```sh
.venv/bin/python scripts/run_article_pipeline.py recipes/article-second-line/recipe.json
```

这是本地单命令脚本串联现有适配器，并将事件和产物登记到工作台；不是 Worker 自动循环调用 Codex 八次。脚本与分镜由当前 Codex 任务编写为可复核配方，确定性步骤自动执行。

流程：源文/素材快照 → 脚本/练习/答案 → 分镜与设计 → Qwen 分段合成 → 独立转录 → 句段时间表/SRT → HyperFrames 预检与整片渲染 → FFmpeg 双遍响度处理 → 最终 QA/全镜抽帧 → 工程/交付包。

本轮自动模式直接完成整片粗版与预检，没有单独的前置人工小样会审。工作台的自动制作记录不等于人工门禁批准。人工 Review 表保持不变。

配方、源文、图像与制作脚本纳入输入指纹；输入变化生成新项目版本。相同版本恢复时核对缓存音频的文本和哈希。本地锁阻止两个脚本同时运行，Worker 在脚本占用资源时不领取新任务。命令行任务中断使用终端，不伪装为可在网页取消的 Worker 任务。
