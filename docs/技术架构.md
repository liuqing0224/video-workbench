# 技术架构与接口

本项目采用公共八阶段、营销/教学两个内容分支和统一模板包。前端 React/TypeScript/Vite；API FastAPI；独立单 Worker；SQLite WAL；本机文件存储。具体依赖版本由 requirements.lock.txt 与两个 package-lock.json 固定。

## 可信来源与执行

内容文件 → 阶段请求（输入哈希、意见、阶段）→ SQLite 队列 → Worker 原子领取 → 隔离运行副本 → Codex 或确定性适配器 → 文件/Schema/时间检查 → 登记产物 → 人工确认或下一阶段。

Codex 通过 exec JSONL 输出日志，最后输出符合 schemas/agent-result.json 的结果。Agent 只写 runs/<id>/work，平台独立保存状态与确认。项目输入发生变化时阻止提升旧运行副本。

Markdown/JSON 保持可读可编辑；SQLite 管 Project、Run、Artifact、Review、Event、ServiceConfig。每个实际输出有 SHA-256。源文件版本与不可变运行产物分别登记。声音修改不使未受影响的内容确认失效；脚本与素材修改沿阶段依赖失效。

## HTTP 接口

| 方法与路径 | 功能 |
|---|---|
| GET /api/session | 本机 HttpOnly 会话，返回阶段列表 |
| GET/POST /api/projects | 列表/创建 |
| GET/PATCH /api/projects/{id} | 状态/带修订号更新配置 |
| GET /api/projects/{id}/files | 文件、哈希与大小 |
| GET/PUT /api/projects/{id}/document | 读取/乐观锁保存 |
| POST /api/projects/{id}/assets | 上传素材、音频、SRT |
| POST /api/projects/{id}/runs | 幂等提交阶段或工具任务 |
| POST /api/runs/{id}/cancel、retry、review | 取消/重试/版本确认 |
| GET /api/runs/{id}/logs | 有界日志尾部 |
| GET /api/projects/{id}/events | SSE，支持 Last-Event-ID |
| GET /api/artifacts/{id}/file | 哈希核验后的流式媒体/下载 |
| POST /api/projects/{id}/comments | 绑定产物的时间点意见 |
| GET /api/services | 配置 |
| PUT /api/services/qwen | 本机 Qwen 地址 |
| POST /api/services/probe | 实际健康与版本探测 |

请求修改须带 X-Video-Request: workbench 与本机会话，来源和 Host 必须符合本机策略。文档 revision 是原文件哈希；配置 revision 由项目查询返回。冲突返回 409，不覆盖新内容。完整类型见服务启动后的 /docs。

## Worker 与工具

任务类型：agent、tts、transcribe、render、qa、package。阶段任务只在前置完成/确认有效时运行；直接工具任务可用于声音试验，不能冒充完整阶段完成。

Worker 文件锁限制单实例；SQLite 原子领取；每 2 秒心跳；超过 30 秒的失联任务转 blocked。命令使用参数数组和独立进程组；取消、超时与正常停止终止子进程。失败不自动重复调用模型。

Qwen 使用实测 synthesize 协议；音色以服务返回元数据和试听为准。ASR 结果可能只有文字，必须保留待校正状态。时间验证器检查 HTML 镜头 data-shot-id、起止时间与统一时间表一致；HyperFrames 自身检查运行时、布局、动效和对比度。

FFmpeg 检查输出轨道、目标属性、响度/真峰值，生成黑帧线索与关键帧；未设目标或检查失败不能通过自动门禁。最终还需人工判断自然度、可读性与分支目标。

## 兼容与升级

旧手册与填写示例保留。项目复制模板，不将示例转换为已确认任务。首版数据库 user_version=1，升级前备份；后续版本以显式迁移脚本升级，不能静默重建用户数据库。

无旁白是制作变体；横竖版首版采用独立项目/输出分别验收，复用相同资料时复制并记录来源。首版以渲染 MP4 做隔离预览，不在管理页面执行生成 HTML。公开发布、多人协作、完整时间轴编辑不在首版范围。
