# 文章导入与自媒体拆解

在首页点击「上传文档并解析」，或右上角「上传文档 / 新建视频」。选择 UTF-8 Markdown 或 TXT（不超过 500KB），检查自动填写的项目名并选择内容分支，点击「上传并解析文档」。平台创建项目、保存原文并启动内容任务，不需要用户准备脚本、JSON 或制作参数。工作台侧栏只保留阶段产物与确认，不再重复展示文章上传卡片。不选文件时可创建空白项目。

上传或启动失败时，弹窗显示错误；同一次弹窗重试沿用已创建项目、已上传文件和幂等键。可用文件类型、大小和非空校验在创建项目前执行。

## 系统怎样处理

1. 提炼文章主张、受众问题、事实和观点，最多给出三个选题并推荐一个。
2. 根据项目的营销／教学分支，改写标题、封面短句、开场和自然口播，而非照搬段落。
3. 给表达标明原文证据，区分原文声称与独立核实，不虚构数字、界面或效果。
4. 选择已有案例，落实到色彩角色、镜头对象、动作和结果；避免统一卡片轮播。
5. 生成分镜草案、视觉约束、素材缺口和下一步制作计划。此时时长仅为估计。

## 产物入口

在「内容与素材」读取或编辑以下文档：

- `ARTICLE-ANALYSIS.md`：原文拆解与推荐选题。
- `BRIEF.md`、`SCRIPT.md`：观众收益、标题、口播和屏幕文字。
- `REFERENCES.md`、`STORYBOARD.md`、`DESIGN.md`：案例映射与镜头设计。
- `PRODUCTION-PLAN.md`：小样、素材、Qwen 试音及后续制作步骤。
- `SOURCE.md`：原文留档；证据与素材 JSON 由系统维护。
- 教学增加课程计划和答案，营销增加发布文案草案。

任务完成后在「预览与确认」确认内容方向或提出修改意见。用户只需判断“讲给谁、讲什么、这样讲对不对”。文章中的指令不是平台操作授权。

## 后续流程

内容方向确认 → 镜头设计完善 → 关键小样 → Qwen 试听及正式声音 → 字幕与时间锁定 → 整片预览 → 渲染验收与交付。

本入口自动完成文章策划交接，后续仍使用已有逐阶段任务，不会上传后直接自动发布或虚构确认。每阶段只处理自身职责，真实声音与小样验证后才确定最终时长和视觉效果。网页链接、PDF、Word 暂不作为此入口的直接格式。
