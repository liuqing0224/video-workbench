# 本机视频制作平台

## 启动与停止

首次安装：`./scripts/setup.sh`。需要 Python 3.11+、Node 22+、FFmpeg/ffprobe 与已登录的 Codex CLI。

启动：`.venv/bin/python scripts/manage.py start`，打开 http://127.0.0.1:8794。
停止：`.venv/bin/python scripts/manage.py stop`。

平台和独立 Worker 写日志到 workspace/api.log、worker.log。服务只监听本机。前端正式构建由同一后端提供；开发时 Vite 的代理保持 API 同源。不要将端口转发至公网。

## 一条视频怎样运行

1. 创建项目，选择营销或教学，填写简报。创建后复制公共与分支模板，不覆盖源模板。
2. 内容与素材页编辑文档、导入素材。JSON 使用原交接字段；文件以项目为根目录，文档位于 documents/。
3. 制作工作台按八阶段提交任务。Codex 在独立运行副本完成当前阶段，平台检查产物后登记。
4. 声音页生成本地 Qwen 分段旁白，试听后在脚本/声音配置关联实际文件；使用独立转录结果校正字幕，或导入 SRT。声画时间由 timing.json 统一管理。
5. 内容、小样、声音/时间、完整预览在预览与确认页审核。无旁白时间阶段不需声音确认。确认针对列出的运行，而不是当前播放器碰巧选中的另一个版本。
6. 在配置中填写目标分辨率、帧率、编码；有音轨时补响度和峰值。完整预览确认后执行渲染验收。技术通过后还要确认声画与分支检查。
7. 交付复盘阶段生成 zip 和哈希清单。平台不自动公开发布。

默认新项目分辨率是便于开始填写的 1920×1080/30fps，可在交付配置修改，不是所有视频通用标准。响度和峰值未设默认通过值。例：`targets` 可包含 `width`、`height`、`fps`、`video_codec`、`audio_codec`、`sample_rate`、`lufs`、`lufs_tolerance`、`true_peak_db`。

## 状态、恢复与修改

- 任务从 queued/running 进入 succeeded、awaiting_review、blocked、failed 或 cancelled。
- 当前任务占用该项目输入；修改前等待或取消。网页保存以文件哈希检查冲突，避免覆盖旧版本。
- 首版按阶段输入判定失效：脚本修改影响后续画面/声音，新增音频不使未受影响的内容确认失效；配置与素材修改采取保守复查。旧产物仍可下载，但不能确认成当前版本。
- 不自动重试模型或语音生成。失败/阻塞后查看运行日志，再使用“按当前输入重试”。
- Worker 以文件锁限制为一个。心跳失效的运行标为中断待恢复；不把残留文件视为完成。
- runs 下的副本是历史证据；不要手动修改。产物下载、确认和打包会重新检查哈希。

## 工具与配置

服务设置探测 Codex、FFmpeg、ffprobe、项目固定版本 HyperFrames 和 Qwen。已识别的 Qwen 协议为 `/health`、`/synthesize`（text/voice/style）与 `/transcribe`（audio 上传）；不是通用 OpenAI API。服务配置仅保存本机 URL，无凭据。

自动转录是独立服务步骤，不代表 TTS 自带精确词级时间。返回缺少可靠时间时保存待校正文本，不制造字幕时间。

阶段 Agent 读取项目 Skills，输出受 schema 约束的 JSON；模型不能代替人工确认。HyperFrames CLI 参数由适配器管理；模型负责 HTML 工程，Worker 负责检查和渲染。HTML 不直接在管理页面执行，预览采用渲染视频，消除同源脚本风险。

## 备份与恢复

先停止服务，再 `.venv/bin/python scripts/manage.py backup --file /绝对路径/video-backup.zip`。

恢复到新目录：`VIDEO_WORKSPACE=/绝对路径/空工作区 .venv/bin/python scripts/manage.py restore --file /绝对路径/video-backup.zip`。

备份包含 SQLite 一致性快照与项目文件，不包含会话令牌、依赖缓存。恢复后重新生成本机会话；未完成任务转为 blocked。核对项目和产物后再开始新任务。不要覆盖已有工作区。

## 验证

- `.venv/bin/python -m pytest -q`：状态、文件边界、冲突、幂等、失效、取消与恢复测试。
- `npm --prefix apps/web run build`：TypeScript 和生产构建。
- 真实工具联调证据在 qa/平台实施检查.md；未完成的试听、预览确认和学习测试单独记录。

## 试制预览与当前限制

workspace/trials 包含真实界面截图、本地 Qwen 声音与 HyperFrames 制作的营销横/竖版、无旁白短版、教学横版。它们是工程联调预览，不是已确认的成片。截图呈现实际界面状态，尚未录制完整鼠标操作；教学小屏控件可读性仍需专门复核。段落文案不是词级对齐字幕。

这些预览通过 scripts/import_trials.py 登记为 trial 产物，不创建阶段通过记录，也不越过人工确认。生产任务仍按真实阶段执行。已有音轨预览尚未设定正式响度目标，自动 QA 保持 incomplete。

首版任务由用户明确启动每个阶段；确认后可启动下一阶段，不自动连续消耗模型调用。取消本机 Qwen 客户端会停止本地等待，但既有服务不提供取消接口，服务端可能继续当前合成；检查服务状态后再重试。
